Case Study案例研究

Detailed Process · Method · Results过程 · 方法 · 结果
01
Product Discovery & Definition产品发现与定义
Identified three core pain points in academic paper reading—high effort to assess value, complex reading paths tied to research goals, and difficulty verifying AI-generated conclusions. Defined AI Overview, AI Deep Reading, and AI Assistant modules and independently built an interactive web prototype. Set product boundaries around trustworthy single-paper reading, no unsupported inference, and no replacement of academic judgment.识别论文阅读中的三类核心痛点：判断论文价值成本高、阅读路径与研究目标耦合复杂，以及 AI 生成结论难以验证。定义 AI 导读、AI 精读与 AI 助手三个模块，并独立完成交互式网页原型。产品边界明确为可信的单篇论文阅读、不做无证据推断、不替代学术判断。
02
AI System ArchitectureAI 系统架构
Established “LLMs for understanding, deterministic systems for rules.” Used the LLM layer for intent understanding, task planning, reasoning, and response generation, while deterministic components handle document parsing, structured retrieval, source anchoring, and verification. Replaced generic RAG with single-document structure-aware RAG and constrained planning through task-to-section routing templates.确立“大语言模型负责理解，确定性系统负责规则”的架构。大语言模型层承担意图理解、任务规划、推理与回答生成；确定性组件负责文档解析、结构化检索、来源锚定与验证。用单文档结构感知 RAG 替代通用 RAG，并通过任务到章节的路由模板约束规划过程。
03
AI Interaction & Trust MechanismsAI 交互与可信机制
Designed a seven-stage workflow—Intent Understanding → Slot Extraction → Path Planning → Retrieval → Evidence Extraction → Reasoning → Verification. Added minimal-source tool routing across selected text, current paper, conversation history, and web search. Required claims to be grounded in page numbers, sections, and source text, with an independent “no evidence, no output” verification layer.设计七阶段工作流：意图理解 → 槽位抽取 → 路径规划 → 检索 → 证据提取 → 推理 → 验证。基于选中文本、当前论文、会话历史和网页搜索进行最小来源工具路由。所有结论必须锚定页码、章节和原文，并设置独立的“无证据，不输出”验证层。
04
Evaluation & Data Experiments评测与数据实验
Built a fixed 24-case evaluation set across Overview, Deep Reading, and Assistant tasks, with each case repeated three times per version. Ran V1 Baseline → V2 Structured → V3 Optimized controlled experiments using content accuracy, evidence grounding, source-location accuracy, tool-routing accuracy, citation accuracy, hallucination rate, and task-completion rate as release gates. Verification-layer injection tests targeted ≥90% detection and ≤5% false positives.围绕导读、精读与助手任务建立固定 24 个案例的评测集，每个版本的每个案例重复 3 次。完成 V1 基线版 → V2 结构化版 → V3 优化版对照实验，以内容准确率、证据锚定、来源定位、工具路由、引用准确率、幻觉率与任务完成率作为上线门禁。验证层注入测试目标为检测率 ≥90%、误报率 ≤5%。
05
Results & Iteration Loop结果与迭代闭环
Improved Overview 78.2→94.7 while severe hallucinations fell 7.5%→0.8%; Deep Reading 76.8→94.4; Assistant 74.1→95.1; tool-routing accuracy 64%→97%; three-run consistency 81%→97%. Established a P0 blocking mechanism, 10-layer bad-case taxonomy, and Root Cause → Fix → Re-run → Regression Test loop.导读从 78.2 提升至 94.7，严重幻觉由 7.5% 降至 0.8%；精读 76.8→94.4；助手 74.1→95.1；工具路由准确率 64%→97%；三次运行一致性 81%→97%。同时建立 P0 阻断机制、10 层失败案例分类体系，以及“根因定位 → 修复 → 重新运行 → 回归测试”的迭代闭环。
